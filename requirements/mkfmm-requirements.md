# 사내 개발 리소스 통합 관리 시스템 요구사항 정의서

## 1. 프로젝트 개요
MessageKey FunctionID MenuID Management = MKFMM

### 1.1 서비스 비전
사내 개발자들이 메시지 리소스 키, 기능 ID, 메뉴 ID 등 개발 공통 리소스를 일관되고 중복 없이 등록·검색·공유할 수 있도록 지원하는 사내 개발 리소스 통합 관리 플랫폼. 권한 기반 사용자 관리와 자동화된 무결성 검증, 완전한 이력 추적을 통해 조직 차원의 리소스 자산화를 실현한다.

### 1.2 핵심 가치 제안

**개발자 관점**
- 동료가 이미 등록한 리소스를 즉시 검색·재사용
- 중복 등록 및 유사 정보 자동 탐지로 실수 방지
- 표준화된 리소스 사용을 통한 코드 일관성 확보

**프로젝트 리더/팀 관리자 관점**
- 권한 기반 사용자 관리로 리소스 변경 통제
- 모든 리소스 변경 이력의 완전한 추적
- IMPORT/EXPORT를 통한 손쉬운 데이터 이관

**조직 관점**
- 사내 표준 리소스의 자산화 및 재사용성 극대화
- Excel/TSV/JSON 배포를 통한 외부 시스템 연동
- 변하지 않는 최상위 관리자 체계 기반의 안정적 거버넌스

### 1.3 핵심 운영 원칙
- **권한 최소화 원칙**: 사용자에게 필요한 최소 권한(Read 또는 Write)만 부여
- **권한 부여 중앙화 원칙**: 관리자만이 다른 사용자에게 권한을 부여할 수 있음
- **이력 우선 원칙**: 로그인, CRUD, IMPORT, EXPORT, 배포 등 모든 작업은 이력으로 남김
- **무결성 우선 원칙**: 리소스 등록/변경 시 중복 검증 및 유사 정보 제안을 자동 수행

## 2. 서비스 구성

### 2.1 주요 구성 요소

**프론트엔드 영역**
- **개발자용 인터페이스**: 메시지 리소스 키, 기능 ID, 메뉴 ID의 검색/조회/등록/변경/삭제 화면, IMPORT/EXPORT 화면
- **관리자용 인터페이스**: 사용자·권한 관리, 배포 관리, 이력 조회 화면

**백엔드 영역**
- **인증/권한 관리 모듈**: 로그인, 세션, 권한 검증, 로그인 이력 처리
- **리소스 관리 모듈**: 메시지 리소스 키, 기능 ID, 메뉴 ID, 내용에 대한 CRUD 처리
- **데이터 무결성 모듈**: 중복 검사 및 유사 정보 탐지·제안
- **이력 관리 모듈**: 검색·CRUD·IMPORT·EXPORT 작업 이력 기록 및 조회
- **배포 관리 모듈**: 전체 데이터 EXPORT(Excel/TSV/JSON) 및 배포 이력 관리

**데이터 저장소**
- **리소스 데이터**: 메시지 리소스 키, 기능 ID, 메뉴 ID, 내용
- **계정/권한 데이터**: 사용자, 권한, 로그인 이력
- **이력 데이터**: 작업 이력, 배포 이력, 감사 로그

### 2.2 사용자 유형 및 권한

| 사용자 유형 | 설명 | 권한 부여 방법 |
|---|---|---|
| **시스템 최상위 관리자** | 시스템 초기 구축 시 자동 생성되어 변하지 않는 관리자. 삭제 및 변경 불가 | 시스템 고정 |
| **관리자(Admin)** | 모든 권한 보유. 사용자 등록/변경/삭제 및 권한 부여 가능 | 최상위 관리자 또는 다른 관리자가 부여 |
| **Write 사용자 (개발자)** | 리소스 검색, 추가, 변경, 삭제, IMPORT, EXPORT 가능 | 관리자가 부여 |
| **Read 사용자** | 리소스 검색 및 EXPORT만 가능 | 관리자가 부여 |

> 권한은 Read와 Write로 구분되며, 관리자만이 다른 사용자에게 권한을 부여할 수 있다. 시스템 최상위 관리자는 시스템 생애주기 동안 변경되지 않는다.

### 2.3 데이터 흐름 개요

**리소스 등록/변경 흐름**
사용자 입력 → 중복 검증(메시지 리소스 키 / 기능 ID / 메뉴 ID / 내용) → 유사 정보 탐지 → 사용자에게 제안 → 사용 여부 선택(기존 사용 / 신규 등록) → 저장 → 작업 이력 기록

**데이터 일괄 처리 흐름**
검색 / 추가·변경·삭제 / IMPORT / EXPORT → 작업 이력 자동 기록

**배포 흐름**
전체 데이터 EXPORT (Excel / TSV / JSON) → 배포 이력 기록 → 외부 시스템/팀 공유

**인증 및 감사 흐름**
로그인 시도 → 인증 검증 → 세션 발급 → 로그인 이력 기록 → 권한 기반 기능 접근 제어 → 권한 변경은 감사 로그로 보관

## 3. 핵심 기능 요구사항

### 3.1 사용자 관리 (User Management)

#### 3.1.1 사용자 인증
**목적**: 시스템 접근 통제 및 보안 확보

**기능 요구사항**:
- 로그인 (사용자 ID / 비밀번호 기반)
- 로그아웃
- 세션 유지 및 만료 처리
- **로그인 이력 관리**:
  - 로그인 시각
  - 접속 IP
  - 로그인 성공/실패 여부
  - 실패 사유
  - 이력 조회 및 필터링

**보안 요구사항**:
- 비밀번호 안전한 저장 (bcrypt 해싱)
- 로그인 시도 제한 (브루트포스 방지)
- 세션 기반 인증

#### 3.1.2 사용자 계정 관리
**목적**: 사용자 계정의 생애주기 관리

**기능 요구사항**:
- 사용자 등록 (관리자만 수행 가능)
- 사용자 정보 변경 (본인 또는 관리자)
- 사용자 삭제 (관리자만 수행 가능, 최상위 관리자는 삭제 불가)
- 사용자 목록 조회 및 검색

#### 3.1.3 권한 관리
**목적**: 사용자별 접근 범위 통제

**기능 요구사항**:
- **권한 종류**:
  - Read 권한 (조회 및 EXPORT 가능)
  - Write 권한 (추가/변경/삭제/IMPORT/EXPORT 가능)
  - 관리자 권한 (모든 권한 + 사용자 관리)
- **시스템 최상위 관리자**:
  - 시스템 초기 구축 시 자동 생성
  - 변경 및 삭제 불가
  - 모든 권한 보유
- **권한 부여 정책**:
  - 관리자만 다른 사용자에게 권한 부여 가능
  - 권한 회수 가능
  - 권한 변경 시 감사 로그 기록

---

### 3.2 리소스 데이터 관리 (Resource Management)

#### 3.2.1 관리 대상 리소스
**목적**: 사내 개발 공통 리소스의 통합 관리

**관리 대상**:
- **메시지 리소스 키**: 다국어/메시지 관리용 키
- **기능 ID**: 기능 단위 식별자
- **메뉴 ID**: 화면 메뉴 식별자
- **내용(Content)**: 각 리소스에 매핑되는 실제 값/설명

**공통 속성**:
- 식별자 (Key/ID)
- 내용
- 설명/비고
- 등록자, 등록 시각
- 최종 수정자, 최종 수정 시각

#### 3.2.2 검색 및 조회
**목적**: 등록된 리소스를 빠르게 탐색

**기능 요구사항**:
- 키워드 검색 (Key, ID, 내용 대상)
- 리소스 유형별 필터 (메시지/기능/메뉴)
- 등록자/수정일 등 메타데이터 기반 필터
- 페이지네이션 및 정렬

#### 3.2.3 추가 / 변경 / 삭제
**목적**: 리소스의 등록 및 유지보수

**기능 요구사항**:
- 신규 리소스 등록 (중복 검증 및 유사 정보 제안 연동)
- 기존 리소스 수정 (변경 전/후 이력 기록)
- 리소스 삭제 (Soft Delete 권장)
- 일괄 변경/삭제 (선택사항)

---

### 3.3 데이터 무결성 및 중복 관리

#### 3.3.1 중복 확인
**목적**: 동일 리소스의 중복 등록 방지

**기능 요구사항**:
- **중복 검사 대상**: 메시지 리소스 키, 기능 ID, 메뉴 ID, 내용
- 추가 및 변경 시점에 자동 검증
- 중복 발견 시 사용자에게 명확한 알림 표시
- 중복 발생 시 등록 차단 또는 사용자 확인 후 진행

#### 3.3.2 유사 정보 제안
**목적**: 의미적으로 유사한 기존 리소스의 재사용 유도

**기능 요구사항**:
- 등록하려는 정보와 **유사한 기존 데이터** 자동 탐지
- 유사도 기준에 따른 후보 리스트 표시 (유사도 점수 포함 가능)
- **사용 여부 선택 옵션**:
  - 기존 리소스 사용 (선택 시 신규 등록 취소)
  - 신규 등록 강행 (선택 사유 입력 가능)
- 선택 결과 이력 기록

---

### 3.4 데이터 작업 및 이력 관리

#### 3.4.1 작업 이력 기록
**목적**: 모든 데이터 작업의 완전한 추적성 확보

**기능 요구사항**:
- **이력 기록 대상 작업**:
  - 검색
  - 추가 / 변경 / 삭제
  - IMPORT
  - EXPORT
- **이력 기록 항목**:
  - 작업 종류
  - 작업자
  - 작업 시각
  - 대상 리소스 식별자
  - 변경 전 / 변경 후 내용
  - 작업 결과 (성공/실패, 실패 사유)

#### 3.4.2 이력 조회
**기능 요구사항**:
- 작업 종류, 작업자, 기간, 리소스 유형별 필터
- 변경 전/후 비교(diff) 보기
- 페이지네이션 및 정렬
- 이력 데이터 EXPORT (감사 목적)

---

### 3.5 IMPORT / EXPORT 및 배포 관리

#### 3.5.1 IMPORT
**목적**: 외부 데이터의 일괄 등록

**기능 요구사항**:
- 파일 업로드 (Excel / TSV / JSON 지원)
- 업로드 데이터에 대한 중복 검증
- 중복/충돌 발생 시 처리 방식 선택 (건너뛰기 / 덮어쓰기 / 사용자 확인)
- IMPORT 결과 리포트 (성공/실패/스킵 건수)
- IMPORT 이력 자동 기록

#### 3.5.2 EXPORT
**목적**: 데이터의 외부 활용 및 백업

**기능 요구사항**:
- **부분 EXPORT**: 검색 결과 또는 선택 데이터에 한정
- **전체 EXPORT**: 전체 리소스 일괄 내보내기
- **지원 형식**: Excel(.xlsx), TSV, JSON
- EXPORT 이력 자동 기록

#### 3.5.3 배포 관리
**목적**: 전체 데이터의 외부 시스템 배포 및 버전 추적

**기능 요구사항**:
- **전체 데이터 EXPORT를 "배포"로 정의**
- 배포 형식: Excel, TSV, JSON 중 선택
- **배포 이력 기록 항목**:
  - 배포 시각
  - 배포 작업자
  - 배포 형식
  - 데이터 범위 (전체 / 조건부)
  - 데이터 건수
  - 배포 버전
- 배포 이력 조회 및 다운로드 재실행 기능
- 배포 버전 관리 (선택사항)

## 4. MVP 개발 범위

### 핵심 기능 (필수)
**목표**: 사내 개발자가 메시지 리소스 키, 기능 ID, 메뉴 ID를 중복 없이 등록·검색·공유하고, 관리자가 사용자 권한과 데이터 배포를 통제할 수 있는 최소 기능 구현

**개발자용 (Write / Read)**:
- 로그인 및 로그아웃
- 리소스 검색 (키워드, 리소스 유형별)
- 리소스 추가 / 변경 / 삭제 (Write 사용자)
- **중복 확인** (메시지 리소스 키, 기능 ID, 메뉴 ID, 내용)
- **유사 정보 제안 및 사용 여부 선택**
- IMPORT (Excel / TSV / JSON)
- EXPORT (Excel / TSV / JSON, 부분/전체)
- 본인 작업 이력 조회

**관리자용 (Admin)**:
- 관리자 로그인 (세션 기반 인증)
- **사용자 관리** (등록 / 변경 / 삭제)
- **권한 부여** (Read / Write)
- 로그인 이력 조회
- 전체 작업 이력 조회 (검색, 추가/변경/삭제, IMPORT, EXPORT)
- **전체 데이터 EXPORT 기반 배포** (Excel / TSV / JSON)
- 배포 이력 조회

**시스템 기본 구성 (필수)**:
- 시스템 최상위 관리자 자동 생성 (변경/삭제 불가)
- 비밀번호 안전 저장 (bcrypt)
- 로그인 시도 제한
- 권한 변경 감사 로그

### 후속 개발 범위 (선택)
**목표**: 사용성 및 운영 효율 향상 (MVP 이후)

- 일괄 변경/삭제 (Bulk Operations)
- 변경 이력 diff (변경 전/후 비교 보기)
- 배포 버전 관리 및 롤백
- 유사도 점수 기반 정교한 추천 (의미 유사도, AI 기반)
- 외부 시스템 자동 연동 (배포 결과를 Webhook/API로 전달)
- 다국어 메시지 리소스 미리보기
- SSO 연동 (사내 인증 통합)
- 이력 데이터 보존 정책 관리 (보관 기간, 자동 아카이빙)

## 부록

### A. 용어 정의

**시스템 일반 용어**
- **MVP**: Minimum Viable Product (최소 기능 제품)
- **API**: Application Programming Interface (애플리케이션 프로그래밍 인터페이스)
- **UI/UX**: User Interface / User Experience (사용자 인터페이스 / 사용자 경험)
- **CRUD**: Create, Read, Update, Delete (데이터의 생성·조회·변경·삭제)
- **RBAC**: Role-Based Access Control (역할 기반 접근 제어)

**리소스 관련 용어**
- **메시지 리소스 키 (Message Resource Key)**: 다국어 메시지, 알림 문구 등 문자열을 식별하기 위한 고유 키
- **기능 ID (Function ID)**: 시스템 내 단위 기능을 식별하는 고유 ID
- **메뉴 ID (Menu ID)**: 화면 메뉴 항목을 식별하는 고유 ID
- **내용 (Content)**: 각 리소스 키/ID에 매핑되는 실제 값 또는 설명

**데이터 관리 용어**
- **중복 확인 (Duplicate Check)**: 동일한 키/ID/내용이 이미 등록되어 있는지 자동으로 검증하는 기능
- **유사 정보 제안 (Similar Information Suggestion)**: 등록하려는 정보와 의미적/형태적으로 유사한 기존 리소스를 자동으로 탐지하여 재사용을 유도하는 기능
- **IMPORT**: 외부 파일(Excel/TSV/JSON)로부터 리소스를 일괄 등록하는 작업
- **EXPORT**: 검색 결과 또는 전체 리소스를 외부 파일(Excel/TSV/JSON)로 내보내는 작업
- **배포 (Deployment)**: 전체 리소스 데이터를 외부 시스템/팀 공유 목적으로 EXPORT하는 공식 작업. 배포 이력으로 별도 관리됨
- **배포 이력 (Deployment History)**: 배포 시점, 작업자, 형식, 데이터 범위, 버전을 포함하는 배포 기록
- **작업 이력 (Work Log)**: 검색·CRUD·IMPORT·EXPORT 등 모든 데이터 작업에 대한 기록

**권한 및 보안 용어**
- **시스템 최상위 관리자 (Root Administrator)**: 시스템 초기 구축 시 자동 생성되어 시스템 생애주기 동안 변경·삭제되지 않는 관리자 계정
- **관리자 (Administrator)**: 모든 권한을 보유하고 다른 사용자에게 권한을 부여할 수 있는 사용자
- **Write 권한**: 리소스 추가·변경·삭제·IMPORT·EXPORT 권한
- **Read 권한**: 리소스 조회 및 EXPORT 권한
- **로그인 이력 (Login History)**: 로그인 시각, IP, 성공/실패 여부 등의 인증 기록
- **감사 로그 (Audit Log)**: 권한 변경 등 시스템 보안에 영향을 주는 행위에 대한 별도 기록
- **bcrypt**: 비밀번호를 안전하게 해싱·저장하기 위해 사용되는 표준 해시 알고리즘
