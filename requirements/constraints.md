# 사내 개발 리소스 통합 관리 시스템 구현 예외사항

## 제외 기능 (구현하지 않음)

### 1. 인증 및 보안
- SSO 연동 (SAML, OAuth, OpenID Connect)
- SNS 로그인 (Google, GitHub, Microsoft 등)
- 다단계 인증 (2FA, OTP, 생체 인증)
- 사내 디렉터리 서비스 연동 (LDAP, Active Directory)
- IP 화이트리스트 / 접속 제한
- 비밀번호 정책 강제 (만료, 복잡도 강제)
- 계정 잠금 자동 해제 워크플로우

### 2. 알림 시스템
- 이메일 발송 (가입 환영, 변경 알림, 배포 알림 등)
- 메신저 알림 (Slack, Microsoft Teams, Discord 등)
- SMS 알림
- 푸시 알림 (모바일, 브라우저)
- 알림 구독 설정 및 관리

### 3. 외부 시스템 연동
- 형상 관리 시스템 연동 (Git, GitLab, Bitbucket, GitHub)
- 이슈 트래커 연동 (Jira, Redmine, Asana)
- 위키/문서 시스템 연동 (Confluence, Notion)
- CI/CD 파이프라인 자동 연동 (Jenkins, GitHub Actions)
- Webhook을 통한 외부 시스템 자동 전송
- API 키 기반 외부 시스템 접근 (외부에서 본 시스템 호출)
- 빌드 시스템 자동 배포 트리거

### 4. 협업 기능
- 리소스 댓글 및 토론
- 멘션(@) 기능
- 리소스 승인 워크플로우 (등록 전 검토/승인)
- 변경 요청 검토(Review) 시스템
- 실시간 동시 편집
- 리소스 즐겨찾기 / 구독
- 활동 피드 (Activity Feed)

### 5. AI / 지능형 기능
- 의미 기반 유사도 추천 (임베딩, AI 기반)
- 자동 번역 (메시지 리소스 다국어 자동 생성)
- 자연어 검색
- 리소스 자동 분류 / 태깅
- AI 기반 명명 규칙 제안
- 오타 / 일관성 자동 검출

### 6. 분석 및 통계
- 사용 통계 대시보드
- 리소스 사용 빈도 / 인기 리소스 분석
- 사용자 활동 리포트
- 데이터 시각화 (차트, 그래프)
- 검색 키워드 트렌드 분석
- 미사용(Dead) 리소스 자동 탐지

### 7. 버전 관리 / 형상 관리
- Git 수준의 본격적인 버전 관리
- 브랜치 / 머지 개념
- 충돌(Conflict) 해결 자동화
- 시점 복원 (Point-in-Time Restore) UI
- 다중 환경(개발/스테이징/운영) 분리 관리

### 8. 다국어 / 국제화 (i18n)
- 시스템 UI 자체의 다국어 지원
- 메시지 리소스 자동 번역
- 다국어 검수 / 비교 도구
- 지역화(Locale) 포맷 관리 (날짜, 통화 등)

### 9. 백업 및 복구
- 자동 백업 스케줄링
- Point-in-Time 복구 UI
- 재해 복구(DR) 기능
- 백업 파일 외부 저장소 자동 업로드 (S3 등)

### 10. 모바일 / 오프라인
- 모바일 네이티브 앱 (iOS, Android)
- 오프라인 모드 / 로컬 캐시 동기화
- 모바일 푸시 알림
- 반응형 모바일 최적화 UI (참고용 PC 우선)

### 11. 라이선스 / 과금
- SaaS 과금 시스템
- 라이선스 관리
- 사용량 기반 과금
- 결제 게이트웨이 연동

### 12. 고급 권한 관리
- 필드 단위 / 행 단위 세분화된 권한
- 그룹 / 조직(부서) 기반 권한
- 프로젝트별 권한 분리
- 권한 위임 / 임시 권한 (Just-in-Time Access)
- 역할(Role) 커스터마이즈 (Read/Write/Admin 외 추가 역할)
- 권한 신청 / 승인 워크플로우

### 13. 컨텐츠 관리
- 이미지 / 파일 첨부 기능
- 리치 텍스트 에디터 (마크다운 외 WYSIWYG)
- 첨부파일 버전 관리
- 미디어 라이브러리

### 14. 고급 IMPORT/EXPORT
- 스케줄 기반 자동 EXPORT
- 외부 시스템(Google Sheets, Notion DB 등) 직접 연동 EXPORT
- 증분(Incremental) EXPORT
- 사용자 정의 EXPORT 템플릿 / 포맷

### 15. 기타
- 시스템 자체에 대한 사용자 피드백 수집 기능
- 인앱 도움말 / 튜토리얼 시스템
- 광고 / 마케팅 기능
- 외부 사용자 공개 API (Public API)
- 챗봇 / 가상 비서 통합
